Vivid User Privacy Settings

General

Applies to every site without its own rule. Setting a global UA is ignored while automatic rotation is on.

Always up to date. On startup, when your connection returns, and at least hourly, this add-on pulls the newest Chrome, Edge and Firefox versions from Google's and Mozilla's official version feeds and rebuilds your agent from them. Your saved global agent is regenerated from the chosen profile, and rotation always uses the newest versions. Per-site rules that you typed by hand stay exactly as typed.

Link to any plain-text file (.txt) with one User-Agent per line — for example a raw GitHub file. Blank lines and lines starting with # are skipped, and quotes or trailing commas are tolerated. When set, it is re-fetched about hourly and agents are picked from it for the matching profile. Nothing is requested from it unless you enter a link.

Requests made (only these, about hourly): your own list link if you set one, Google's Chrome version feed and Mozilla's Firefox version feed. Order of preference: online list → version feeds → built-in estimates, so generation always works, even offline. Pasting your own text in the box above makes it a custom UA that is never changed.

My custom User-Agents (optional)

One per line, either Label | User-Agent or just the User-Agent. Printable ASCII only, 8–512 characters, up to 100.

When automatic rotation is set to a Random profile (any, desktop or mobile), it will sometimes pick one of your agents instead of a built-in one.

Saved agents appear in the profile lists (global User-Agent, per-site rules, the popup) under My custom agents, and Random — from my custom agents becomes an option for automatic rotation. They are used exactly as typed and never changed or updated. Leave this blank to ignore the feature.

Automatic rotation

A site keeps the User-Agent it first saw until you close all its tabs, so pages don't break, log you out or ask for verification when a rotation happens mid-visit. Sites you open later get the newest one.

Per-site rules

A rule for example.com also covers its subdomains. The most specific rule wins and always beats the global/rotating UA.

Deep stealth

Removes Firefox-only APIs (moz*, buildID, -moz- CSS), adds Chromium-only ones (window.chrome, deviceMemory, connection, getBattery, bluetooth, V8-style Error.stack) and trims Firefox-specific request headers. Turn this off if a site breaks.

Version overrides

Offline, Chrome/Edge/Opera and Safari versions are estimated from release cadence. If a site rejects the estimate, type the real current major version here. Firefox profiles use your installed Firefox version automatically.

Privacy level

Balanced: DNT + Global Privacy Control, origin-only referrer, tracking-parameter stripping, WebRTC public-interface only, Firefox tracker blocking, no ping/prefetch. Strict: adds a stricter referrer policy, canvas noise, WebGL masking, geolocation block, beacon block, WebRTC leak block and cookie partitioning. A preset only fills in the form — press Save to apply it.

Request headers & links

Adds DNT: 1 to requests. Few sites honour it.

Opens http:// pages as https://. Local addresses and sites in “Sites to skip” are excluded. If a site stops loading, add it to that list.

Adds Sec-GPC: 1, a legally binding opt-out of data selling in several regions.

Removes tracking tags (utm_*, fbclid, gclid, YouTube si= and similar) from addresses you open, and skips click-logging / “You are leaving…” redirect pages (Google, Facebook, Instagram, YouTube, Steam, Reddit, LinkedIn, DuckDuckGo and more) so you land on the real page.

Audio (fingerprint protection)

Adds tiny noise to Web Audio readbacks so audio can't be used to identify you.

Fingerprint hardening (page JavaScript)

Slightly changes canvas readbacks. Image editors and web games may notice.

Location requests from pages always fail with “permission denied”.

Also covers the Permissions API and all iframes, and sends Permissions-Policy: geolocation=().

Stops navigator.sendBeacon, which analytics scripts use to ping as you leave a page.

These only change what pages can read from JavaScript. Web Workers keep Firefox's real values, and nothing here changes your real IP address (see the IP & Proxy tab). Turn a feature off or add the site to the skip list if a site misbehaves (image editors and web games can notice canvas noise).

Firefox privacy settings

These change real Firefox preferences while Vivid User Privacy is installed. Turning them off or uninstalling the add-on restores your own settings.

Keeps Firefox's built-in tracker blocking turned on.

Stops <a ping> from telling sites which links you click.

Turns off link and DNS prefetching, so Firefox doesn't contact sites you haven't opened.

Advanced (can break sites)

Firefox's own protection: UTC time zone, rounded timers and window size. Overrides several values set by this add-on.

Keeps cookies and cache separate for each site. Can break logins that span sites.

These settings change what web pages can read about your device. They follow the Privacy tab's master switch and its "sites to skip" list. Pick values that agree with each other (and with your User-Agent): a Windows User-Agent with an Apple GPU and macOS fonts is easier to spot than no spoofing at all.

Graphics card (WebGL)

navigator.gpu can report your real graphics card.

Changes WEBGL_debug_renderer_info and the WebGL vendor/renderer strings. Other WebGL details (texture limits, extensions) still come from your real GPU, and canvases inside Web Workers are not covered.

Screen

Also fakes innerWidth, outerHeight, screenX … as a maximised window on that screen.

The window option makes the numbers consistent, but pages that size things from innerWidth in JavaScript will see a fixed value (CSS layout is unaffected). Leave it off if a site looks wrong.

Fonts

Fonts that fingerprinting scripts probe for (about 300 names) and that are not in the chosen set are made to look not installed: pages that ask for them get the fallback font instead. This hides fonts; it cannot make a font appear that your computer does not have, so "match" works best when your real OS is close to the spoofed one. Web fonts that sites load themselves are unaffected. Fonts you rely on in a web app can be added to the list or the site added to the Privacy tab's skip list.

Time zone

Changes getTimezoneOffset, getHours() and friends, Date#toString, toLocale*String and Intl.DateTimeFormat. It does not change how new Date(2024, 0, 1) or Date.parse("2024-01-01 10:00") read their input, and your IP address still points at your real location — use the IP & Proxy tab and pick a matching zone. Language is set in the Privacy tab.

Hardware & devices

enumerateDevices() returns an empty list, since the list is a fingerprint. Video calls may stop finding your devices.

speechSynthesis.getVoices() returns an empty list.

Canvas, audio and battery protection are in the Privacy tab (Audio, Fingerprint hardening, and "blend in" values).

More spoofing

Removes navigator.getBattery(). Level and charging state can identify you for short periods.

Removes navigator.connection (connection type and speed estimate).

navigator.getGamepads() returns an empty list. Browser games won't see your controller.

Simple prefers-color-scheme and prefers-reduced-motion checks answer as light theme and no reduced motion. Sites may still look dark if their CSS follows your real setting.

Simple matchMedia() checks for forced colours (high contrast), prefers-contrast, inverted colours, reduced transparency and reduced data answer as “not set”. These reveal assistive-technology use and make your browser rarer. CSS @media rules in a page's stylesheet still follow your real setting.

screen.orientation reports landscape for a desktop User-Agent and portrait for a phone or tablet one, so it agrees with the device you claim. matchMedia("(orientation: …)") and CSS still use your real window.

navigator.mediaCapabilities keeps saying whether a format is supported, but always answers “smooth, not power-efficient”, so hardware acceleration (which depends on your GPU) is not revealed. Video sites may pick a different quality or codec.

Match: scripts inside a Web Worker report the same User-Agent as the page (applies when a non-Firefox identity and deep stealth are on). Leave alone: workers see your real browser, which can contradict the page. Block: Worker and SharedWorker throw an error, so workers cannot fingerprint you, but many sites (maps, editors, video, chat) will break.

Stops tabs from linking you across sites. Every tab of a site keeps the same User-Agent (even if automatic rotation's “keep the same User-Agent” option is off), and a page opened from another site starts with an empty window.name and no window.opener link back to that site. A few sign-in pop-ups that talk to the page that opened them may stop working; add that site to the “sites to skip” list if so.

Rounds performance.now() to 100 ms to blunt timing attacks. Games, animations and benchmarks may stutter.

navigator.storage.estimate() reports 10 GB available and nothing used, hiding your real disk size.

Hide your IP address

How this works. A browser add-on cannot hide your IP by itself — your traffic has to leave through someone else's server. Vivid User Privacy routes Firefox through a proxy you choose and plugs the usual leaks (DNS, WebRTC). It does not provide a proxy.
Free options that are actually safe:
  • Tor — install Tor Browser (or the tor service) and leave it running, then add the Tor entry below. Free, no account. Slower, and some sites block Tor.
  • Your own server — ssh -D 1080 user@your-server gives you a free SOCKS5 proxy at 127.0.0.1:1080 (cloud free tiers work).
  • Any proxy/VPN SOCKS5 or HTTP endpoint you already have access to.
Avoid random "free proxy lists". Whoever runs a free public proxy can see — and alter — your unencrypted traffic and often logs it. If you use one, assume nothing sensitive (logins, banking) is safe on it.

Proxies

The round button picks the proxy used when rotation is off. "Separate circuit per site" (Tor) uses a different Tor circuit — and exit IP — for each website you visit. "Test" saves your settings first.

Routing

Local addresses (localhost, 192.168.x.x, 10.x.x.x, *.local …) always bypass the proxy.

Leak protection

SOCKS proxies only. Stops DNS leaks.

Active while the proxy is on.

If the proxy fails, proxied traffic pauses for 10 s instead of risking a direct connection.

Check it. Always verify, especially after changing settings. Also, Firefox only lets an add-on handle private windows if you enable Run in Private Windows for Vivid User Privacy in about:addons — otherwise private-window traffic is not proxied.

Your real browser

detecting…

Read from Firefox itself (not from a web page), so this is always the truth, whatever Vivid User Privacy is sending to sites.

What do websites detect?

Runs the same checks a site's "true browser" script would run — User-Agent, platform, Client Hints, Firefox-only features, error-stack format, Web Workers — and tells you which ones still reveal your real browser.

Backup

Exported files do not include proxy passwords. Proxy credentials are stored unencrypted in Firefox's local extension storage.
